2. Description of Application 2. Описание сервиса и приложения

Men's Log is an offline-capable, local-first personal calendar and wellness journal designed for discreet tracking of relationship milestones, cycle observations, and personal notes. The Application features hardware-backed cryptographic security (SQLCipher AES-256) and optional encrypted backup synchronization directly to your private Google Drive application container (appDataFolder).

Men's Log — автономное локальное приложение-календарь и журнал самочувствия, разработанное для конфиденциального учёта дат отношений, фаз циклов и персональных заметок.
